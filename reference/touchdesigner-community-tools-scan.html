What changed in 2025–2026

Two patterns run through almost everything in this scan. They are the spine of the 2027 series.

Era 01

The custom operator family era

T3D grew into TDFam, and TDFam became the substrate for a wave of new families: GSOPs (Gaussian splats), L2D (2D lighting), MOPs (modular synthesis), POPX, AML (Apple ML), and Function Store's FNS family. Builders are no longer shipping single .tox files — they are shipping operator families with installers, versioning, and docs.

Era 02

The MCP era

At least five distinct TouchDesigner MCP servers exist as of October 2026 — TwoZero, Embody's Envoy, 8beeeaaat's touchdesigner-mcp, Pantani's tdmcp / MindDesigner, and Derivative's own official TDMCP, launched September–October 2026 — plus a same-named package on PyPI. AI agents can now build networks directly inside TouchDesigner.

Two corrections from the scan: the creator is Darien Brito, not “Darian.” And TwoZero is not separate from 404zero — TWOZERO is made by 404.zero (+ setupdesign); twozero.ai and the 404zero.com docs are the same product line.

Real-time AI generation

The diffusion cluster, from the reference implementation to the native-operator challengers.

  • StreamDiffusionTD — DotSimulate. The reference implementation: v0.4.1, SDXL-Turbo with ControlNet / IP-Adapter / FaceID / StreamV2V / live LoRA on TensorRT locally (Windows, NVIDIA 6 GB+ VRAM, 24 GB recommended, Python 3.11.9 exactly, CUDA 12.8), or via the Daydream cloud backend with no local GPU, including on Mac. Daydream page
  • ComfyTD — DotSimulate. A TOX to control ComfyUI workflows from inside a TD network. Distinct from ComfyUI-TD, a ComfyUI-side node for sending media back to TD — a name collision worth flagging in any catalogue.
  • SD TOP — Unveil Studio / Simo. Native-operator alternative with no Python or TensorRT model conversion. €15 for a 6-month licence via Lemon Squeezy; RTX 30/40/50 series.
  • TouchDiffusion — CtrlAltCtrl. Beta real-time diffusion tool announced on Patreon around October 2026; details unverified.
  • TwoZero ZOPs. Hosted generation as wired operators — 1,361 models at scan time, chat / image / video, cost shown before a run and failed generations not charged. Generation, but cloud-hosted rather than local diffusion.
  • Adjacent AI: AML's Diffusion and CoreML operators (on-device, macOS), Nurbs' depth + relight .tox (Metric3D v2 via ONNX), TwoZero's Depth AI and Background Removal rudiments, and TD-ML for training and inference on CHOP data.

Method & caveats

  • Basis: web-index research as of October 24, 2026. Full primary pages were fetched through the index for TwoZero, Function Store / FNSTools, DotSimulate's StreamDiffusionTD docs, Embody, 404zero's TwoZero docs, and Derivative's TDMCP GitHub. Nothing here is labelled “verified live” — a separate live check could not resolve DNS for twozero.ai or functionstore.tools on Oct 24, which was a research-window failure, not evidence the sites are down.
  • Pricing rule: a price appears only where a public page exposed it. Patreon generally does not expose full tier tables to non-members, so most Patreon tier prices are unverified in this scan.
  • Conflicts carried, not resolved: TwoZero's minimum build is 2025.33230+ on twozero.ai and 2025.33070+ in the 404zero.com docs. Embody's is 2025.33230+ on the current site versus 2025.32280 on an earlier mirror. Envoy's tool count is 52 on the current site versus 45 in an MCP-repository listing. Resolve each by testing the current .tox.
  • Licences not found on public pages for SARV, T3D, RayTK (name), MediaPipe-TD (Torin's repo), Embody (specific name), AML, MOPs, GeoPix (specific name), Pantani's tdmcp, Dewpoint, Nurbs, Okamirufu, AVY, and Warpa / SimpleMixer. Check each repo or maker before redistributing anything.
  • Spelling variants in sources: 404zero's Alexander Letcius (Derivative) vs Letsius (Interactive & Immersive HQ). RayTK's author is “Tekt / t3kt” on primary sources; a full name on one course page was not corroborated and is not used here.
